# Стратегия агента

## Phase 2 — baseline (2 фичи)

Простейший Dellacherie-style scorer. Для активного пентамино перебираем
все валидные `(rot, x)` приземления (только канонические rotation —
SPEC §4 fix), для каждого симулируем `apply_lock` на локальной копии
стакана и считаем:

```
score = w_h · sum(column_heights) + w_holes · holes
```

Минимум — лучшее приземление. Tie-break: меньший `x`, потом меньший
`rot` (детерминизм для тестов).

**Стартовые веса** (`Weights(w_h=1.0, w_holes=2.0)`) — прикидочно,
дыры дороже простой высоты. Tuning откладываем до Phase 3.

### Что baseline делает хорошо

- Не плодит дыры (когда `w_holes` большой относительно `w_h`).
- Завершает линию когда такой вариант даёт минимум.
- На пустом стакане работает как ожидается.

### Что baseline делает плохо

- Не различает «положил плоско» vs «надстроил столб» — суммарная
  высота одна и та же. Фикс — **bumpiness** в Phase 3.
- Не учитывает следующую фигуру из `tick.my_queue[0]` — каждое
  решение ad-hoc. Фикс — **1-piece lookahead** в Phase 4.
- Ловит топ-аут в течение 5–10 секунд на `default`-пресете
  (см. эмпирику в `.claude/AI.md`).

## Action sequencing

Когда сервер сообщает новое active_piece, агент сразу планирует
placement и кладёт в `own`-очередь сервера серию атомарных команд:

1. `rot_cw` или `rot_ccw` (берём кратчайшее направление: до 2 шагов
   максимум)
2. `left` или `right` (по `target_x − cur_x`)
3. `drop`

Сервер обрабатывает по одной команде за тик из очереди `own`. На
`default`-уровне (`ticks_per_row=100`, 200 мс/ряд) ~10 команд
укладываются в один цикл гравитации. На высоких уровнях (Phase 4+)
понадобится оптимизация.

## Desync-detection

После каждого `locked: true` в tick'е агент шлёт `info.state` query.
В следующем-после-обработки тике сервер отдаёт
`tick.p.info.state.own = "crc32:XXXXXXXX"`, и мы сверяем с локальным
`Board.crc32_state()`.

Mismatch → `WARNING` в лог + инкремент `agent.desync_count`. На live
матчах Phase 2 `desync_count = 0` за 34 lock'а — сильный сигнал, что
наш `apply_lock` сходится с серверным.
