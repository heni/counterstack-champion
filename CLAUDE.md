# Правила проекта и накопленные знания

Реальное содержимое живёт в **`.claude/`** (не трекается git'ом):

- **`.claude/CLAUDE.md`** — workflow-правила, конвенции,
  обязательные шаги. Читать в начале каждой сессии.
- **`.claude/AI.md`** — накопленные знания о проекте:
  нетривиальные решения, грабли, design-rationale, который не
  следует напрямую из кода. Пополнять по ходу — когда узнал
  что-то, что должно пережить текущую сессию.
- **`.claude/backlog.md`** — roadmap и идеи, ещё не начатые.

Директория `.claude/` исключена через `.gitignore` намеренно.
Привязка к git-веткам приводила к тому, что заметки «исчезали»
при переключении между ветками; вынос наружу делает их
персистентными между ветками и сессиями.

Свежий `git clone`? Начинаем с чтения `.claude/CLAUDE.md` если
файл уже создан локально, иначе инициализируем по этому README.
