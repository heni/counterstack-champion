# counterstack-champion

С нуля написанный Python-агент для арены
[CounterStack](http://counter-stack.rutsh.com/) — пентикс (тетрис
на 12 пентамино F/I/L/N/P/T/U/V/W/X/Y/Z), 500 Hz сервер, JSON
Lines поверх TCP, протокол v0.5.

Цель к концу занятия: агент подключается к публичному тестовому
серверу, проходит handshake, играет полный квалификационный матч
и сабмитится на платформу с не-тривиальным результатом.

## Быстрый старт (на занятии)

```bash
uv venv
source .venv/bin/activate
uv pip install -e '.[dev]'
pytest                                            # baseline smoke
python -m champion --help                         # CLI surface
python -m champion counter-stack.rutsh.com:9017   # smoke vs test server
```

## Что знаем про окружение

- **SPEC** — http://counter-stack.rutsh.com/spec.html (v0.5,
  2026-04-25). Ключевые разделы: §5.3 (формат `tick`), §11
  (протокол: транспорт, жизненный цикл, обработка ошибок), §12
  (очереди сообщений сервера), §13 (конфиг игры).
- **Правила квалификации** — http://counter-stack.rutsh.com/quals.
  Образ ≤ 1 ГБ, ENTRYPOINT принимает `host:port` единственным
  позиционным аргументом, контейнер выходит сам по `match_end`.
- **Тестовый сервер** — `counter-stack.rutsh.com:9017`, публичный,
  без SLO. 2 мс jitter гарантирован только на закрытом
  quals-сервере; через интернет — больше, это ожидаемо.
- **Скоринг квалы** — 10 матчей на пресете `pentris-7` (фигуры
  I/L/N/P/T/Y/Z) с 10 seed'ами, итог — truncated mean (отбрасываем
  2 лучших и 2 худших, среднее по 6).

## Протокол вкратце

- Транспорт: TCP, JSON Lines, UTF-8, разделитель `\n`,
  `max_message_bytes = 8192`.
- Конверт: `{"t":"<тип>","q":"<очередь>","p":{...}}`. Поле `q`
  обязательно для матчевых клиентских сообщений (`own`, `opp`,
  `info`, `keepalive`) и отсутствует в до-матчевых (`hello`,
  `ready`) и в любых серверных.
- Жизненный цикл соединения:
  `hello → welcome → ready{config_name} → match_start → tick* →
  match_end`.
- Версия протокола: 5 — должна совпадать у клиента и сервера,
  иначе тех.поражение.
- Полный текст — в SPEC по ссылке выше.
